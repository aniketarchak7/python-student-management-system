# python-student-management-system
Python Student Management System - Developed a simple menu-driven Student Management System using Python. The application allows users to add student details, view all students, and search for students by name. It uses functions, lists, dictionaries, loops, and conditional statements to manage student records efficiently.

# Project Description
The Python Student Management System is a simple, menu-driven application developed using Python. It allows users to add student details, view all student records, and search for a student by name.

This project demonstrates basic Python programming concepts, including functions, lists, dictionaries, loops, conditional statements, and user input handling.

# Features
- Add new student details (name, age, and course).
- View all registered students.
- Search for a student by name.
- Display appropriate messages when students are found or not found.
- Simple menu-driven interface.

# Technologies Used
- Python 3
- Built-in Python functions and data structures

# How to Run the Project

# Step 1: Install Python
Download and install Python 3 from [https://www.python.org/downloads/](https://www.python.org/downloads/).

# Step 2: Download the Code
Clone this repository or download the source code to your computer.

# Step 3: Open the Project Folder
Open the folder in VS Code or your preferred code editor.

### Step 4: Run the Program
Open a terminal in the project folder and execute:

```bash
python student_management.py
```

If your system uses the `python3` command, run:

```bash
python3 student_management.py
```

# Step 5: Use the Application
Follow the on-screen menu to add students, view student records, search for a student, or exit the program.
